# NCES CCD schools data (local)

Generated by `node scripts/import-nces-schools.mjs`.

| Path | Purpose |
|------|---------|
| `raw/` | Downloaded ZIP + extracted CSV (large; gitignored) |
| `schools.json` | Full filtered high-school set (gitignored) |
| `manifest.json` | Provenance + counts (safe to commit if small) |
| `schools.sql` | Optional bulk INSERT (`--sql`) |

**Source:** [NCES Common Core of Data](https://nces.ed.gov/ccd/files.asp) school directory (file 029).  
**License:** U.S. government work / public domain. Cite NCES CCD.

CCD is **public** schools only. Private programs (e.g. Mater Dei) are not in CCD.

Synthetic demo schools remain at `src/data/seed/schools.json` for player seed IDs.
