# Takkle Design System

## World
Night-game athletic premium: official visit dossier under Friday night lights. Deep navy field, electric orange brand signal, sparingly used turf green.

## Palette
- Ground: `#070B14`
- Field / elevated surface: `#0E1624`
- Accent (Takkle): `#FF6A00`
- Turf accent: `#1FAF6B`
- Bone text: `#F5F0E8`
- Secondary text: `#94A3B8`

## Type
- Display: Bebas Neue (brand, headlines, score digits)
- Body: system UI sans

## Product rules that affect UI
- Tackle Score™ only (1.0–10.0) — never star ratings
- Film is a first-class “live window” on profiles
- High School NIL Rules always linked in nav + footer
- Synthetic demo data must be labeled

## Surfaces
- Homepage: persuade — brand hero, claim CTA, discovery
- Profile `/site/player/[slug]`: dossier — score digits + film window
- Discover / Rankings / Admin: operate
- NIL Rules: read (existing resource preserved)
